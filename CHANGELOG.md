## 0.1.0 - 2026-04-26

* Initial Dropify release with `DropifyEntry`, `DropifyController`, `RawDropify`, static, async, paginated, multi-select, and form-field dropdown APIs.
* Added inherited theming, Material theme bridging, stable test selectors, example gallery pages, robot journey tests, accessibility coverage, and README documentation.
* Refined pre-release API and internals: removed unused `errorTextBuilder`, exported row builder typedefs, added Flutter-style diagnostics, hardened controller replacement, and synchronized external controller changes with form validation.
